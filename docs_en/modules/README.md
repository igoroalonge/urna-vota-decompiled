# Application modules (reconstructed TSE code)

One chapter per reconstruction unit (~100 functions each). Every chapter explains its subsystem and ends with
a **complete mapping table**: wasm function index → reconstructed symbol → source file. The C++ is in
[`src/`](../../src). Units were produced by `tools/wasmmap/units.py` (`analysis/units.json`); each was
reconstructed by one reviewer and checked line by line against the decompiled code by an adversarial one
(`analysis/w2_reconstruct.results.json` records every issue found and fixed).

There are **41 units** holding **3,911 functions** (`analysis/units.json`): u01–u40 from the first pass (3,903)
and u41 (8), the leftovers re-attributed to TSE code afterwards, including func 5922 `vota::LegendaValida`,
which was added during the consistency pass.
