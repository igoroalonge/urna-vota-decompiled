# Módulos da aplicação (código do TSE reconstruído)

Um capítulo por unidade de reconstrução (~100 funções cada). Cada capítulo explica o seu subsistema e termina com
uma **tabela de mapeamento completa**: índice da função wasm → símbolo reconstruído → arquivo-fonte. O C++ está em
[`src/`](../../src). As unidades foram produzidas por `tools/wasmmap/units.py` (`analysis/units.json`); cada uma foi
reconstruída por um revisor e conferida linha a linha contra o código descompilado por um revisor adversarial
(`analysis/w2_reconstruct.results.json` registra cada problema encontrado e corrigido).

São **41 unidades** com **3.911 funções** (`analysis/units.json`): u01–u40 da primeira passada (3.903)
e u41 (8), as sobras reatribuídas ao código do TSE depois, incluindo a func 5922 `vota::LegendaValida`,
que foi adicionada durante a passada de consistência.
